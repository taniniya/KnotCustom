## 主な追加・変更点

上流 v3.1.2 の機能に加えて、このフォークでは次の4点を追加・変更しています。

1. **他人のメッセージの既読記録＆長押し「既読者」表示**
   自分の送信メッセージだけでなく、**相手（他人）のメッセージを誰がいつ既読にしたか**を記録します。メッセージを長押しすると「既読者」が一覧で出るので、グループで誰が見たかをその場で確認できます。
2. **既読傾向・時間帯集計**
   記録した既読データを集計し、**メンバーごとに既読がつきやすい時間帯**（例: 「20〜23時台が多い（14件）」）や直近の既読時刻を表示します。「既読履歴」画面のヘッダから「📊 既読傾向」で開けます。
3. **定型文クイックランチャー（自由入力ブロック・選択ブロック・先頭 `.` スイッチ）**
   よく送る文章やコマンドを「定型文」として登録し、トーク画面から1タップで入力欄に入れられます。`{入力:項目名}` / `{選択:A|B}` / `{選択+:A|B}` のブロックを書いておくと、使うときに埋めるだけで完成します。詳しくは「[定型文の使い方](#定型文の使い方)」へ。
   v3.1.14 で、以前の「コマンド」は**「定型文」に一本統合**しました（タブ・コマンド管理画面・プリセットは廃止）。
4. **Custom by taniniya 表記**
   アプリ名、設定画面のクレジット、リリースノートに改変者表記を追加しました。

## 定型文の使い方

### 1. 登録する

**Knot設定 →「チャット」→「定型文管理」→「＋ 追加」**

- **タイトル**（任意）: 一覧に出す名前。空なら本文の1行目が出ます。
- **本文**: そのまま入力欄に入れたい文字列。ブロックを混ぜられます。
- 編集画面の **「＋ 自由入力ブロック」** と **「＋ 選択ブロック」** を押すと、カーソル位置にブロックが入ります。
- 一覧の項目をタップすると「編集 / 上へ / 下へ / 削除」が選べます。

### 2. ブロックの書き方

| 書き方 | 意味 | 使うときの画面 |
| --- | --- | --- |
| `{入力:項目名}` | 使うたびに文字を入れる欄。`項目名` は入力欄のヒントになります。例: `{入力:金額}`、`{入力:@ユーザー}` | 入力欄が出る |
| `{選択:A\|B}` | A・B のどれか1つを選ぶ。`\|`（または `｜`）で区切ります。例: `{選択:表\|裏}` | 選択肢がボタンで並ぶ |
| `{選択+:A\|B}` | 上の選択に加えて、**自由入力もできる**（`+` 付き）。例: `{選択+:100\|500\|1000\|all}` | ボタン＋入力欄が出る |

- ブロックは1つの定型文にいくつでも入れられ、**書いた順**に上から埋めていきます。
- 埋めずに「入力欄に入れる」を押すと、そのブロックは `{入力:金額}` の形のまま残ります（中途半端な文が勝手に送られないようにするため）。
- `{` `}` がブロックの形になっていない部分は、そのままの文字として入ります。

例:

```
{入力:名前}さん、こんにちは。{選択:今日|明日}の{選択+:午前|午後|19時}はどうですか？
```

### 3. 先頭に `.` を付けるスイッチ

**設定 →「チャット」→「定型文の先頭に . を付ける」**、または**ランチャー上部の「先頭に . を付ける」**で切り替えます（どちらで変えても即座に連動します）。

- ON のとき、定型文を入力欄に入れるときに先頭へ `.` を付けます（`/slot …` のようなコマンドを、`.` 始まりのテキストとして送りたいとき用）。
- すでに `.` で始まる定型文は二重にしません。空白だけの定型文には付けません。

### 4. 呼び出す

| 場所 | 操作 |
| --- | --- |
| **トーク画面の＋パネル** | 入力欄横の「＋」→ パネル下部の **「定型文」アイコン**（と「. オン／. オフ」スイッチ）。パネルを閉じると消えます。 |
| **トーク画面の ⚡ ボタン** | 設定で「トーク画面にランチャーボタンを出す」をONにすると、入力欄の上に出ます。長押しで隠せます。 |
| **＋メニュー** | チャットタブ右上の＋メニューの「定型文」（設定でON/OFF）。 |
| **Knot設定** | デバッグメニューの「Templates」からも開けます（動作確認用）。 |

- **ブロックが無い定型文**: タップすると即座に入力欄へ入り、ランチャーが閉じます。
- **ブロックがある定型文**: 組み立て画面が開きます。選択肢はボタン、自由入力は入力欄（開くとキーボードが出ます）。プレビューで完成形を確認してから **「入力欄に入れる」**。
- どちらの場合も**送信はしません**。入力欄に入るだけなので、`@メンション` の補完や文の修正をしてから送れます。
- 入力欄が見つからない画面ではクリップボードにコピーし、その旨を表示します。

### 5. 以前の「コマンド」データについて

v3.1.13 以前の「コマンド一覧」（`command_entries`）は、v3.1.14 では**読み込みません**。設定ファイルに残っていてもクラッシュせず、一覧にも出ません（上流のコマンドプリセット26件も削除しました）。残したいコマンドは、定型文として登録し直してください。

## 既読者表示・既読傾向の使い方

- トーク内のメッセージを**長押し →「既読者」**で、そのメッセージを誰がいつ既読にしたかを確認できます（自分のメッセージ・他人のメッセージの両方）。
- **「📊 既読傾向」**（既読履歴画面のヘッダ、または「既読者」ダイアログ内）で、メンバーごとの既読が多い時間帯と直近の既読時刻を集計して表示します。
- 記録はKnotの既読記録機能が有効なときだけ溜まります。データは端末内のKnotのDBに保存され、外部へは送りません。

## インストール・アップデート

### Root環境

1. [Vector](https://github.com/JingMatrix/Vector/releases) など、API 102 と互換性のあるXposed環境をインストールします。
2. **[このフォークの Releases](https://github.com/taniniya/KnotCustom/releases) から `Knot-Custom-by-taniniya.apk` をインストール**し、マネージャー上でモジュールを有効化します。
3. 対象アプリとしてLINEを選択します。
4. LINEを再起動し、Knotのモジュール設定から各機能を有効化してください。
   - モジュール設定へのアクセス: ホームタブ右上の設定ボタンを長押し、またはLINE設定内の追加項目から。

### 非Root環境（NPatch）

**！！！導入前に必ずトーク履歴をバックアップしてください！！！**

#### 1. 事前準備

1. [Fork版NPatch](https://github.com/Nich87/NPatch) をインストールします。
2. [MicroG-RE](https://github.com/MorpheApp/MicroG-RE) をインストールします。
3. MicroG-REを開き、`最適化を無効化` をタップして電池の最適化を無効にします。その後 `セルフチェック` を開き、表示されている権限をすべて許可します。
4. MicroG-REの `アカウント` を開き、トーク履歴のバックアップに使ったGoogleアカウントでログインします。

#### 2. パッチとインストール

5. NPatchを開き、ストレージのアクセス権限と使用するディレクトリを設定します。
6. **[このフォークの Releases](https://github.com/taniniya/KnotCustom/releases) から `Knot-Custom-by-taniniya.apk` をダウンロードしてインストール**します。
7. `パッチを開始` を押し、パッチ方法を選択します。
   > `プロキシからダウンロードしてパッチ` を推奨します。APKMirrorなどから自分で用意する場合は、動作確認済みのLINEバージョンを選んでください。
8. LINEのバージョンまたはAPKを選び、`新しいパッチ` 画面で `MicroG対応を強制的に有効化` が有効になっていることを確認して、右下の `パッチを開始` を押します。モジュールとして **Knot (Custom by taniniya)** を選択してください。
9. パッチ完了後、右下の `インストール` を押してインストールします（Shizukuがあれば自動）。

#### 3. 初期設定とトーク履歴の復元

10. LINEを起動してログインし、トーク履歴復元の画面でGoogleアカウントを選んで復元します。
11. LINEホームのバナーからKnotが使うディレクトリを設定し、ホーム右上の設定ボタンを長押ししてKnotのモジュール設定を開きます。
12. 各機能を有効化してください。

### アップデート（新しい版へ）

**Knotの設定はアプリのデータとして残ります。** 署名は同じデバッグ鍵なので、上書きインストールで引き継がれます。

- **Root環境**: 新しい `Knot-Custom-by-taniniya.apk` を上書きインストール → Xposedマネージャーでモジュールが有効なままか確認 → **LINEを再起動**。
- **非Root環境（NPatch）でモジュールを埋め込んでパッチした場合**:
  1. 新しい `Knot-Custom-by-taniniya.apk` を上書きインストール（旧 `Knot-Custom-by-taniniya-3.1.13.apk` などは残しておくと戻せます）。
  2. NPatchを開き、LINEの `パッチを開始` → パッチ方法を選択 → `新しいパッチ` 画面で先ほどと同じ設定（`MicroG対応を強制的に有効化`）を確認。
  3. モジュールとして新しい Knot を選んで `パッチを開始` → 完了後 `インストール`（上書き）。トーク履歴はそのまま残りますが、念のためバックアップを。
  4. LINEを起動し、Knot設定で各機能が有効か確認します。
- **非Root環境でNPatchのマネージャーからモジュールを読み込む設定の場合**: モジュールAPKを更新して **LINEを再起動**するだけで反映されます。
- 上流の公式版から乗り換える場合は署名が異なるため、一度アンインストールが必要です。

```bash

# local.properties に sdk.dir を書き、JDK 17 と Android SDK (compileSdk 34) を用意
```
